Using the word "dropdown" in the prompt and what it does

**Problem**<br />How can you create a report where the user can switch between individual reporting months and the figures update automatically?<br /><br />**Solution**<br />Use the word "dropdown" in the prompt so the AI agent creates a report with a month selection that automatically refreshes the figures for the selected month.
