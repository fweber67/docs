Dashboards are the heart of FinanzDash. They display financial metrics, charts, and widgets for a selected company.

## View a dashboard

Client users see dashboards and AI reports as cards and can view them, but not edit them.

1. After signing in, you land in the dashboard view automatically
2. Select a company from the list on the left (you can filter with the search bar or press the `/` key)
3. All available dashboards and the [published reports](/en/finanzdash-ki-berichte) created with the AI agent are displayed for the selected company
4. Click a dashboard to see its reports, or click "View" on a published report to display that report.

## Report types

A dashboard can contain several report types, which are provided by default:

- **KPI dashboard** – Metrics such as revenue and EBITDA as tiles
- **P&L dashboard** – Profit and loss statement with year-over-year comparison
- **Bank balances** – Development of today's bank balances compared to the previous day
- **Working capital** – Chart showing working capital and its development
- **Year comparison** – Monthly year-over-year comparison of individual P&L categories
- **Monthly trend report** - Monthly trend report of individual P&L categories

## Structure of the default report types

### **Account selection by category (basis: Austrian standard chart of accounts)**

| **Category** | **Selected accounts** | **Logic** |
| :-- | :-- | :-- |
| **Revenue** | All accounts starting with `4` | Sum of all `4xxx` accounts |
| **Direct costs** | All accounts starting with `5` | Sum of all `5xxx` accounts |
| **Gross profit** | — | Revenue minus direct costs |
| **Personnel costs** | All accounts starting with `6` | Sum of all `6xxx` accounts |
| **Other expenses** | All accounts starting with `7`, **excluding account** `7736` | Sum of `7xxx` minus depreciation |
| **Depreciation** | Only account `7736` | Single specific account |
| **Financial expenses** | All accounts starting with `8`, **excluding account** `8500` | Sum of `8xxx` minus taxes |
| **Taxes** | Only account `8500` | Single specific account |

### **How subtotals are calculated**

- **Gross profit** = Revenue − Direct costs
- **EBITDA** = Gross profit − Personnel costs − Other expenses
- **EBIT** = EBITDA − Depreciation (account 7736)
- **EBT** (earnings before taxes) = EBIT − Financial expenses
- **Net income after taxes** = EBT − Taxes (account 8500)

Account `7736` (depreciation) is pulled **out** of "Other expenses" (the `7` series) so that EBITDA does not include depreciation, and account `8500` (taxes) is pulled out of "Financial expenses" (the `8` series) so that EBT is calculated before taxes. Each row shows both month-to-date (MTD) and year-to-date (YTD) values with a year-over-year comparison.

## Create a dashboard (administrator)

1. Select a company from the list on the left
2. Click "Add dashboard"
3. Enter a name and, optionally, a description
4. Click "Create"
5. The new dashboard appears in the list

## Edit a dashboard (administrator)

1. Select a company from the list on the left
2. Click "Edit" on the dashboard
3. Change the name and description
4. Click "Update"
5. The changes appear in the list

## Delete a dashboard (administrator)

1. Select a company from the list on the left
2. Click the delete icon on the dashboard
3. Confirm with "OK"
4. The dashboard, including all of its reports, is deleted

## Add a report (administrator)

1. Open a dashboard by clicking its dashboard card
2. Click "Add report" at the top right
3. Enter a report name
4. Select a report type from the list
5. Select data source(s) for this report
6. Click "Create report"

## Edit reports (administrator)

1. Select a dashboard from the list on the left
2. Click the edit icon on the report
3. Change the name, report type, or data sources
4. Click "Update report"
5. The updated report appears in the dashboard

## Delete reports (administrator)

1. Select a dashboard from the list on the left
2. Click the delete icon on the report
3. Confirm with "OK"
4. The report is deleted from the dashboard

## Lock the layout (administrator)

You can lock the dashboard layout to prevent accidental moves. The lock can be released at any time, and the previous positions are restored. To do this, click the "Locked" button at the top right to unlock, or "Unlocked" to lock.

## Arrange and resize dashboard reports (administrator)

- **Unlock** the layout first
- **Move** – Drag and drop a report to a different position
- **Resize** – Drag the edges of a report to make it larger or smaller
- **Positions** are saved automatically
- **Lock** the layout again

## Arrange published reports (administrator)

- Drag the **grip handle** on a report to reorder reports
- **Changes** are saved automatically.
