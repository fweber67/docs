Dashboards are the heart of FinanzDash. They display financial metrics, charts, and widgets for a selected company.

## View a dashboard

1. After signing in, you land in the dashboard view automatically
2. Select a company from the list on the left (you can filter with the search bar or press the `/` key)
3. All available dashboards for the selected company are displayed
4. Click a dashboard to see its widgets

## Widget types

A dashboard can contain several widget types:

- **KPI dashboard** – Metrics such as revenue, profit, and margin shown as tiles
- **P&L dashboard** – Profit and loss statement with year-over-year comparison
- **Bank balances** – Bank balance trends over time
- **Working capital** – Chart of working capital and its development
- **Year comparison** – Comparison of metrics between years

## Create a dashboard (administrator)

1. Select a company from the list on the left
2. Click "Add dashboard"
3. Enter a name and, optionally, a description
4. The new dashboard appears in the list

## Add a widget (administrator)

1. Open a dashboard
2. Click "Add widget"
3. Choose a widget type and enter a name
4. Configure the widget (for example, select a data source)
5. Save the widget

## Arrange and resize widgets (administrator)

- **Move** – Drag and drop a widget to another position
- **Resize** – Drag the edges of a widget to make it larger or smaller
- Positions are saved automatically

## Lock the layout (administrator)

You can lock the dashboard layout to prevent accidental changes. You can unlock it again at any time, and the previous positions are restored.

## For client users

Client users see dashboards as cards and can only view them, not edit them. They do not have any management features.
