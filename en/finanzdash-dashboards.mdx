Dashboards are the heart of FinanzDash. They display financial metrics, charts, and widgets for a selected company.

## View a dashboard

1. After signing in, you land in the dashboard view automatically
2. Select a company from the list on the left (you can filter with the search bar or press the `/` key)
3. All available dashboards for the selected company are displayed
4. Click a dashboard to see its widgets

## Report types

A dashboard can contain several widget types:

- **KPI dashboard** – Metrics such as revenue and EBITDA as tiles
- **P&L dashboard** – Profit and loss statement with year-over-year comparison
- **Bank balances** – Development of today's bank balances compared to the previous day
- **Working capital** – Chart showing working capital and its development
- **Year comparison** – Monthly year-over-year comparison of individual P&L categories
- **Monthly trend report** - Monthly trend report of individual P&L categories

## Create a dashboard (administrator)

1. Select a company from the list on the left
2. Click "Add dashboard"
3. Enter a name and, optionally, a description
4. Click "Create"
5. The new dashboard appears in the list

## Add a report (administrator)

1. Open a dashboard
2. Click "Add report"
3. Enter a report name
4. Select a report type
5. Select the uploaded file(s) as the data source(s) for this report
6. Click "Create report"

## Lock the layout (administrator)

You can lock the dashboard layout to prevent accidental moves. The lock can be released at any time, and the previous positions are restored. To do this, click the "Locked" button at the top right to unlock, or "Unlocked" to lock.

## Arrange and resize reports (administrator)

- **Unlock** the layout first
- **Move** – Drag and drop a report to a different position
- **Resize** – Drag the edges of a report to make it larger or smaller
- **Positions** are saved automatically
- **Lock** the layout again

## For client users

Client users see dashboards as cards and can only view them, not edit them. They have no administration features.
