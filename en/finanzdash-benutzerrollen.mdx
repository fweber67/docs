FinanzDash distinguishes three user roles with different permissions. Your role determines which menu items and features you see.

## Client user

Users with the "client user" role have read-only access. They can:

- View dashboards for companies assigned to them
- View published reports
- Switch between assigned companies

They cannot manage companies, users, data, or reports. In the sidebar, they only see the "Dashboards" menu item.

## Administrator

Administrators are firm employees who manage data and users. They can:

- Create, edit, and delete companies
- Invite and delete users
- Upload, replace, and delete financial data
- Connect and use the DATEV account
- Create and edit dashboards and reports
- Create and publish AI reports (if enabled by the super administrator)
- Assign reports to companies

Administrators are limited to the scope of the firm(s) they are assigned to. They then only see companies and users of those firm(s).

Administrators are marked with a shield icon (turquoise).

## Super administrator

The super administrator has the most extensive rights. They can do everything an administrator can, plus:

- Manage other users (promote and demote)
- Configure AI models (API key, model)
- Enable and disable AI report access for administrators
- Assign token quotas (Starter, Standard, Professional, Custom)
- Connect and use the DATEV account
- View and filter all firms
- Assign companies to multiple users at once

Super administrators are marked with a crown icon (gold).

## Role overview

| Feature | Super admin | Administrator | Client user |
| --- | :-: | :-: | :-: |
| View dashboards | Yes | Yes | Yes |
| Manage companies | Yes | Yes | No |
| Manage users | Yes | Yes | No |
| Upload data sources | Yes | Yes | No |
| Edit dashboards | Yes | Yes | No |
| Create AI reports | Yes | Yes (if enabled) | No |
| Change AI settings | Yes | No | No |
| DATEV interface | Yes | Yes | No |
| Manage administrators | Yes | No | No |
