As an administrator, you manage all users of FinanzDash. You can invite new users, change roles, and delete users.

## View users

1. Click "Users" in the sidebar
2. You see all users with name, email, role, and last sign-in
3. Use the search bar to filter by name or email
4. The role is color-coded: super admin (crown, gold), administrator (shield, turquoise), user (no icon)

## Invite a user

1. Click "Add user"
2. Fill in the form:
   - **Name** – Full name of the user
   - **Email** – The email address the invitation is sent to
   - **Role** – Administrator or user (client)
3. Click "Save"

The new user receives a welcome email with a link to set up their password. Once they set the password, they can sign in.

## Edit a user

1. Click the edit icon on a user
2. You can change the name and role
3. Save the changes

## Delete a user

1. Click the delete icon on a user
2. An impact analysis is displayed showing which data belongs to this user (dashboards, reports, etc.)
3. Confirm the deletion

Only super administrators can delete other users. Super administrators cannot be deleted while they are still super admin.

## Manage super administrators

Only super administrators can promote others to super administrator or demote them:

1. Open the super admin management
2. Select an administrator
3. Click "Promote" or "Demote"

## Reset a user's password

As an administrator, you can reset a user's password:

1. On a user, click "Reset password"
2. The user receives an email with a link to set a new password

## Firm assignment

Administrators can be restricted to specific firms. If an administrator is assigned to only certain firms, they only see the companies and users of those firms.

Client users are assigned to a firm so that the correct dashboards can be shared with them.
