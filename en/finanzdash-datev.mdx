The DATEV integration allows super administrators to automatically retrieve financial data via the DATEV API, without uploading files manually.

## Prerequisites

- You need the **super administrator** role
- The DATEV client number must be set for the company (see [Manage companies](/finanzdash-unternehmen))

## Connect DATEV

1. Click "Data sources" in the sidebar
2. Select a company
3. Click "Connect DATEV"
4. A new window opens with the DATEV sign-in page
5. Sign in with your DATEV credentials
6. Grant permission for FinanzDash
7. The window closes automatically and the connection is established

Once the connection is successful, the connection status is shown as "Connected".

## Retrieve the trial balance

After the DATEV connection has been established, you can retrieve the trial balance (SuSa):

1. Click "Retrieve SuSa"
2. FinanzDash retrieves the data for the current and previous fiscal year
3. The retrieved data appears in the data sources list
4. The data is immediately available for dashboards and AI reports

## DATEV client list

You can also retrieve the list of your DATEV clients via the DATEV interface. This helps you create the correct companies in FinanzDash.

## Disconnect

1. Click "Disconnect"
2. The DATEV connection is closed
3. Data that has already been retrieved is kept

You can reconnect at any time.

## Security

- The DATEV access tokens are stored encrypted
- All API calls are recorded in an audit log (with timestamp, duration, and status)
- Tokens are refreshed automatically when they expire
- Only super administrators can use the DATEV interface
