Using the word "dropdown" in the prompt and what it does

**Problem**<br />How can you create a report where the user can switch between individual reporting months and the figures update automatically?<br /><br />**Solution**<br />Use the word "dropdown" in the prompt so the report includes a month selector. When the user changes the selected month, the values refresh automatically based on the chosen period.
