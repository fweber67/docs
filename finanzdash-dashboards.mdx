Dashboards sind das Herzstueck von FinanzDash. Sie zeigen Finanzkennzahlen, Diagramme und Widgets fuer ein ausgewaehltes Unternehmen an.

## Dashboard ansehen

1. Nach der Anmeldung landen Sie automatisch in der Dashboard-Ansicht
2. Waehlen Sie links ein Unternehmen aus der Liste aus (Sie koennen mit der Suchleiste filtern oder die Taste `/` druecken)
3. Fuer das ausgewaehlte Unternehmen werden alle verfuegbaren Dashboards angezeigt
4. Klicken Sie auf ein Dashboard, um dessen Widgets zu sehen

## Widget-Typen

Ein Dashboard kann mehrere Widget-Typen enthalten:

- **KPI-Dashboard** – Kennzahlen wie Umsatz, Gewinn, Marge als Kacheln
- **GuV-Dashboard** – Gewinn- und Verlustrechnung mit Vergleich zum Vorjahr
- **Bankguthaben** – Entwicklung der Bankguthaben ueber Zeit
- **Working Capital** – Chart zum Working Capital und dessen Entwicklung
- **Jahresvergleich** – Vergleich von Kennzahlen zwischen Jahren

## Dashboard erstellen (Administrator)

1. Waehlen Sie ein Unternehmen aus der Liste links
2. Klicken Sie auf "Dashboard hinzufuegen"
3. Geben Sie einen Namen und optional eine Beschreibung ein
4. Das neue Dashboard erscheint in der Liste

## Widget hinzufuegen (Administrator)

1. Oeffnen Sie ein Dashboard
2. Klicken Sie auf "Widget hinzufuegen"
3. Waehlen Sie einen Widget-Typ und vergeben Sie einen Namen
4. Konfigurieren Sie das Widget (z.B. Datenquelle auswaehlen)
5. Speichern Sie das Widget

## Widgets anordnen und vergroessern (Administrator)

- **Verschieben** – Ziehen Sie ein Widget per Drag-and-Drop an eine andere Position
- **Groesse aendern** – Ziehen Sie an den Raendern eines Widgets, um es zu vergroessern oder zu verkleinern
- Die Positionen werden automatisch gespeichert

## Layout sperren (Administrator)

Sie koennen das Dashboard-Layout sperren, um versehentliche Verschiebungen zu verhindern. Die Sperre kann jederzeit wieder aufgehoben werden, wobei die vorherigen Positionen wiederhergestellt werden.

## Fuer Mandantenbenutzer

Mandantenbenutzer sehen Dashboards als Karten und koennen diese nur ansehen, nicht bearbeiten. Sie haben keine Verwaltungsfunktionen.
