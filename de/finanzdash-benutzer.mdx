Als Administrator verwalten Sie alle Benutzer von FinanzDash, die Ihrer Kanzlei zugeordnet sind. Sie können neue Benutzer einladen, Rollen ändern und Benutzer löschen.

## Benutzer ansehen

1. Klicken Sie in der Seitenleiste auf "Benutzer"
2. Sie sehen alle Benutzer mit Name, E-Mail, Rolle und letzter Anmeldung
3. Nutzen Sie die Suchleiste, um nach Name oder E-Mail zu filtern

## Benutzer einladen

1. Klicken Sie auf "Benutzer hinzufügen"
2. Füllen Sie das Formular aus:
   - **Vorname** – Vollständiger Vorname des Benutzers
   - **Nachname** - Vollständiger Nachname des Benutzers
   - **E-Mail** – Die E-Mail-Adresse, an die die Einladung gesendet wird
   - **Kanzlei** – Ordnen Sie den Benutzer einer Kanzlei zu
3. Klicken Sie auf "Einladung senden"

Der neue Benutzer erhält eine Willkommens-E-Mail mit einem Link zum Einrichten seines Passworts. Nach dem Einrichten des Passworts kann er sich anmelden.

## Benutzer löschen

1. Klicken Sie auf das Lösch-Symbol eines Benutzers
2. Es wird eine Auswirkungsanalyse angezeigt, die zeigt, welche Daten diesem Benutzer gehören (Dashboards, Berichte etc.)
3. Bestätigen Sie die Löschung durch klicken auf "Benutzer löschen"

Nur Super-Administratoren können andere Benutzer löschen. Super-Administratoren können nicht gelöscht werden, solange sie Super-Admin sind.
