Als Administrator verwalten Sie alle Benutzer von FinanzDash. Sie koennen neue Benutzer einladen, Rollen aendern und Benutzer loeschen.

## Benutzer ansehen

1. Klicken Sie in der Seitenleiste auf "Benutzer"
2. Sie sehen alle Benutzer mit Name, E-Mail, Rolle und letzter Anmeldung
3. Nutzen Sie die Suchleiste, um nach Name oder E-Mail zu filtern
4. Die Rolle wird farbig markiert: Super-Admin (Krone, gold), Administrator (Schild, tuerkis), Benutzer (kein Symbol)

## Benutzer einladen

1. Klicken Sie auf "Benutzer hinzufuegen"
2. Fuellen Sie das Formular aus:
   - **Name** – Vollstaendiger Name des Benutzers
   - **E-Mail** – Die E-Mail-Adresse, an die die Einladung gesendet wird
   - **Rolle** – Administrator oder Benutzer (Mandant)
3. Klicken Sie auf "Speichern"

Der neue Benutzer erhaelt eine Willkommens-E-Mail mit einem Link zum Einrichten seines Passworts. Nach dem Einrichten des Passworts kann er sich anmelden.

## Benutzer bearbeiten

1. Klicken Sie auf das Bearbeiten-Symbol eines Benutzers
2. Sie koennen den Namen und die Rolle aendern
3. Speichern Sie die Aenderungen

## Benutzer loeschen

1. Klicken Sie auf das Loesch-Symbol eines Benutzers
2. Es wird eine Auswirkungsanalyse angezeigt, die zeigt, welche Daten diesem Benutzer gehoeren (Dashboards, Berichte etc.)
3. Bestaetigen Sie die Loeschung

Nur Super-Administratoren koennen andere Benutzer loeschen. Super-Administratoren koennen nicht geloescht werden, solange sie Super-Admin sind.

## Super-Administrator verwalten

Nur Super-Administratoren koennen andere zu Super-Administratoren befördern oder herabstufen:

1. Oeffnen Sie die Super-Admin-Verwaltung
2. Waehlen Sie einen Administrator aus
3. Klicken Sie auf "Befoerdern" oder "Herabstufen"

## Passwort eines Benutzers zuruecksetzen

Als Administrator koennen Sie das Passwort eines Benutzers zuruecksetzen:

1. Klicken Sie bei einem Benutzer auf "Passwort zuruecksetzen"
2. Der Benutzer erhaelt eine E-Mail mit einem Link zum Neusetzen seines Passworts

## Kanzlei-Zuordnung

Administratoren koennen auf bestimmte Kanzleien beschraenkt werden. Wenn ein Administrator nur bestimmten Kanzleien zugewiesen ist, sieht er nur deren Unternehmen und Benutzer.

Mandantenbenutzer werden einer Kanzlei zugeordnet, damit die richtigen Dashboards fuer sie freigegeben werden koennen.
