FinanzDash nutzt eine E-Mail- und Passwortanmeldung. Diese Seite erklärt alle Schritte von der ersten Anmeldung bis zum Zurücksetzen des Passworts.

## Anmelden

1. Öffnen Sie FinanzDash in Ihrem Browser
2. Geben Sie Ihre E-Mail-Adresse und Ihr Passwort ein
3. Klicken Sie auf "Anmelden"

Nach erfolgreicher Anmeldung sehen Sie je nach Rolle die Dashboard-Ansicht oder die Verwaltungsoberfläche.

### Kontosperre

Nach mehreren fehlgeschlagenen Anmeldeversuchen wird Ihr Konto vorübergehend gesperrt. Sie sehen dann einen Countdown, der anzeigt, wie lange Sie warten müssen, bevor Sie es erneut versuchen können.

## Passwort einrichten (Erstmalige Anmeldung)

Wenn ein Administrator Sie zu FinanzDash einlädt, erhalten Sie eine Willkommens-E-Mail mit einem Link zum Einrichten Ihres Passworts.

1. Öffnen Sie die E-Mail und klicken Sie auf den Link
2. Sie gelangen auf eine Seite, auf der Sie ein neues Passwort festlegen können
3. Ihr Passwort muss mindestens 12 Zeichen lang sein
4. Nach dem Speichern können Sie sich mit E-Mail und Passwort anmelden

## Passwort zurücksetzen

Wenn Sie Ihr Passwort vergessen haben:

1. Klicken Sie auf der Anmeldeseite auf "Passwort vergessen?"
2. Geben Sie Ihre E-Mail-Adresse ein
3. Sie erhalten eine E-Mail mit einem Link zum Zurücksetzen
4. Klicken Sie auf den Link und vergeben Sie ein neues Passwort

## Sprache ändern

FinanzDash ist auf Deutsch und Englisch verfügbar. Sie können die Sprache über den Sprachumschalter oben rechts in der Seitenleiste wechseln. Die Einstellung wird für Ihr Benutzerkonto gespeichert.

## Sitzungsüberwachung

FinanzDash überwacht Ihre Sitzung auf Inaktivität. Wenn Sie länger nicht aktiv sind, werden Sie gewarnt und können die Sitzung verlängern. Bei fortgesetzter Inaktivität werden Sie automatisch abgemeldet.
