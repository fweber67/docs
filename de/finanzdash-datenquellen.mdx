Datenquellen sind die Grundlage für Dashboards und KI-Berichte. Sie können als **Administrator** Finanzdaten als Datei manuell hochladen, mit einer Datei im Cloud Speicher verbinden oder per DATEV-Schnittstelle automatisch abrufen.

## Datei manuell hochladen

1. Klicken Sie in der Seitenleiste auf "Datenquellen"
2. Wählen Sie ein Unternehmen aus der Dropdown-Liste
3. Wählen Sie die Buchhaltungsquelle: DATEV MVZ Export, BMD Export oder Sonstige
4. Ziehen Sie die Datei per Drag-and-Drop in das Upload-Feld oder klicken Sie, um eine Datei auszuwählen
5. Unterstützte Formate: CSV, XLSX, XLS, XML, TXT

### DATEV-Datei verarbeiten

Wenn Sie als Buchhaltungsquelle "DATEV MVZ Export" auswählen, wird die hochgeladene CSV-Datei automatisch verarbeitet:

- Die DATEV-CSV wird in eine strukturierte Excel-Datei umgewandelt
- Ein Fortschrittsbalken zeigt den Verarbeitungsfortschritt an
- Die verarbeitete Datei steht anschließend für Dashboards und Berichte zur Verfügung

## Cloud-Speicher verbinden

Administratoren können FinanzDash mit SharePoint oder OneDrive verbinden. Dadurch lassen sich Dateien direkt aus dem Cloud-Speicher importieren und später automatisch aktualisieren.

1. Öffnen Sie in der Seitenleiste den Bereich „Datenquellen“
2. Klicken Sie auf „Cloud-Speicher verbinden“
3. Melden Sie sich im geöffneten Fenster bei Ihrem Cloud-Konto an
4. Erteilen Sie FinanzDash die erforderlichen Berechtigungen
5. Nach erfolgreicher Verbindung wird der verbundene Cloud-Account angezeigt

Die Verbindung kann jederzeit getrennt werden. Bereits importierte Datenquellen bleiben dabei erhalten.

### Datei aus dem Cloud-Speicher importieren

Nach der Verbindung können Sie Dateien direkt aus Ihrem Cloud-Speicher auswählen:

1. Klicken Sie auf „Aus Cloud hinzufügen“
2. Wählen Sie zwischen den zuletzt verwendeten Dateien und der Ordneransicht
3. Suchen Sie nach der gewünschten Datei
4. Wählen Sie die Buchhaltungsquelle aus
5. Wählen Sie bei einer Verknüpfung den Aktualisierungsmodus (automatisch oder mit Bestätigung)
6. Klicken Sie auf "Hinzufügen"

Unterstützte Dateiformate sind CSV, TXT, XLSX, XLS und XML. Die maximale Dateigröße beträgt 50 MB. DATEV-Dateien werden beim Import automatisch verarbeitet, wenn DATEV als Buchhaltungsquelle ausgewählt ist.

## Datenquellen ansehen

Unter dem Upload-Bereich sehen Sie eine Liste aller Datenquellen des ausgewählten Unternehmens. Diese Liste enthält sowohl manuell hochgeladene, mit dem Cloud Speicher verbundene Dateien als auch per DATEV-Schnittstelle abgerufene Daten.

## Datei herunterladen

Klicken Sie auf das Download-Symbol neben einer Datei, um sie herunterzuladen.

## Datei ersetzen

Wenn Sie eine Datei durch eine neuere Version ersetzen möchten:

1. Klicken Sie auf das Ersetzen-Symbol
2. Eine Warnung zeigt an, welche Berichte auf diese Datei zugreifen und betroffen sind
3. Wählen Sie das Buchhaltungssystem aus
4. Laden Sie die neue Datenquelle manuell hoch bzw. starten Sie die Datev-Übernahme für das entsprechende Wirtschaftsjahr (siehe [Summen- und Saldenliste abrufen](/de/finanzdash-datev))
5. Klicken Sie auf "Neue Datei prüfen"
6. Wenn die neue Datei kompatibel ist, können Sie diese mit Klick auf "Datenquelle ersetzen" hochladen
7. Die alte Datei wird ersetzt und alle Berichte, in denen die Datenquelle verwendet wird, werden automatisch aktualisiert

## Datenquelle mit Cloud-Datei verknüpfen und synchronisieren

Eine bestehende Datenquelle kann mit einer Datei im Cloud-Speicher verknüpft werden. Dadurch kann FinanzDash erkennen, wenn sich die Cloud-Datei geändert hat. FinanzDash prüft täglich um 4.05 Uhr CET, ob sich eine Cloud-Datei und synchronisiert diese, sofern sie sich verändert hat.

Für die Verknüpfung stehen zwei Modi zur Verfügung:

- **Automatisch aktualisieren** – Neue Cloud-Daten werden automatisch übernommen
- **Vor Aktualisierung benachrichtigen** – FinanzDash zeigt zunächst an, dass eine neue Version verfügbar ist. Die Übernahme muss anschließend bestätigt werden

Wie verknüpfe ich eine Cloud-Datei?

1. Klicken Sie auf „Mit Cloud-Datei verknüpfen“
2. Wählen Sie zwischen den zuletzt verwendeten Dateien und der Ordneransicht
3. Suchen Sie nach der gewünschten Datei
4. Wählen Sie bei einer Verknüpfung den Aktualisierungsmodus 
5. Klicken Sie auf "Verknüpfen"

Eine verknüpfte Datenquelle zeigt ihren aktuellen Synchronisierungsstatus an:

- **Verknüpft** – Die Verbindung ist aktiv
- **Aktualisierung verfügbar** – Eine neue Cloud-Version wartet auf Übernahme
- **Fehler** – Die Synchronisierung ist fehlgeschlagen

Bei einem Fehler können Sie die Synchronisierung erneut versuchen. Eine wartende Aktualisierung kann direkt aus der Datenquellenliste übernommen werden. Die Cloud-Verknüpfung kann außerdem jederzeit geändert oder entfernt werden.

## Datei löschen

1. Klicken Sie auf das Lösch-Symbol neben einer Datei 
2. Sie erhalten eine Information und Warnung, welche Berichte diese Datenquelle nutzen 
3. Wenn die Datei mit einer Cloud-Datei verknüpft ist, wird auch diese Abhängigkeit angezeigt 
3. Bestätigen Sie die Löschung durch klicken auf "Trotzdem löschen"

## DATEV-Schnittstelle

Administratoren können die DATEV-API-Schnittstelle nutzen, um Finanzdaten automatisch abzurufen. Details dazu finden Sie auf der Seite [DATEV-Integration](/de/finanzdash-datev).
